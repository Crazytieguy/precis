  144→## Comparison to failure
  145→
  146→The `anyhow::Error` type works something like `failure::Error`, but unlike
  147→failure ours is built around the standard library's `std::error::Error` trait
  148→rather than a separate trait `failure::Fail`. The standard library has adopted
  149→the necessary improvements for this to be possible as part of [RFC 2504].
  …
  155→## Comparison to thiserror
  156→
  157→Use Anyhow if you don't care what error type your functions return, you just
  158→want it to be easy. This is common in application code. Use [thiserror] if you
  159→are a library that wants to design your own dedicated error type(s) so that on
  160→failures the caller gets exactly the information that you choose.

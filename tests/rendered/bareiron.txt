README.md
  1→# bareiron
  2→Minimalist Minecraft server for memory-restrictive embedded systems.
  3→
  4→The goal of this project is to enable hosting Minecraft servers on very weak devices, such as the ESP32. The project's priorities are, in order: **memory usage**, **performance**, and **features**. Because of this, compliance with vanilla Minecraft is not guaranteed, nor is it a goal of the project.
  6→- Minecraft version: `1.21.8`
  7→- Protocol version: `772`
  8→
  9→> [!WARNING]
  10→> Currently, only the vanilla client is officially supported. Issues have been reported when using Fabric or similar.

  1→#!/usr/bin/env bash
  2→
  3→# Check for registries before attempting to compile, prevents confusion
  4→if [ ! -f "include/registries.h" ]; then
  5→  echo "Error: 'include/registries.h' is missing."
  6→  echo "Please follow the 'Compilation' section of the README to generate it."
  7→  exit 1
  8→fi
  9→
  10→# Figure out executable suffix (for MSYS compilation)
  11→case "$OSTYPE" in
  12→  msys*|cygwin*|win32*) exe=".exe" ;;
  13→  *) exe="" ;;
  14→esac
  15→
  16→# mingw64-specific linker options
  17→windows_linker=""
  18→unameOut="$(uname -s)"
  19→case "$unameOut" in
  20→  MINGW64_NT*)
  21→    windows_linker="-static -lws2_32 -pthread"
  22→    ;;
  23→esac
  24→
  25→# Default compiler
  26→compiler="gcc"
  27→
  28→# Handle arguments for windows 9x build
  29→for arg in "$@"; do
  30→  case $arg in
  31→    --9x)
  32→      if [[ "$unameOut" == MINGW64_NT* ]]; then
  33→        compiler="/opt/bin/i686-w64-mingw32-gcc"
  34→        windows_linker="$windows_linker -Wl,--subsystem,console:4"
  35→      else
  36→        echo "Error: Compiling for Windows 9x is only supported when running under the MinGW64 shell."
  37→        exit 1
  38→      fi
  39→      ;;
  40→  esac
  41→done
  42→
  43→rm -f "bareiron$exe"
  44→$compiler src/*.c -O2 -Iinclude -o "bareiron$exe" $windows_linker
  45→"./bareiron$exe"

readme.md
  1→# Beszel
  2→
  3→Beszel is a lightweight server monitoring platform that includes Docker statistics, historical data, and alert functions.
  5→It has a friendly web interface, simple configuration, and is ready to use out of the box. It supports automatic backup, multi-user, OAuth authentication, and API access.
  6→
  7→[![agent Docker Image Size](https://img.shields.io/docker/image-size/henrygd/beszel-agent/latest?logo=docker&label=agent%20image%20size)](https://hub.docker.com/r/henrygd/beszel-agent)
  8→[![hub Docker Image Size](https://img.shields.io/docker/image-size/henrygd/beszel/latest?logo=docker&label=hub%20image%20size)](https://hub.docker.com/r/henrygd/beszel)
  9→[![MIT license](https://img.shields.io/github/license/henrygd/beszel?color=%239944ee)](https://github.com/henrygd/beszel/blob/main/LICENSE)
  10→[![Crowdin](https://badges.crowdin.net/beszel/localized.svg)](https://crowdin.com/project/beszel)
  11→
  12→![Screenshot of Beszel dashboard and system page, side by side. The dashboard shows metrics from multiple connected systems, while the system page shows detailed metrics for a single system.](https://henrygd-assets.b-cdn.net/beszel/screenshot-new.png)
  14→## Features
  15→
  16→- **Lightweight**: Smaller and less resource-intensive than leading solutions.
  17→- **Simple**: Easy setup with little manual configuration required.
  18→- **Docker stats**: Tracks CPU, memory, and network usage history for each container.
  19→- **Alerts**: Configurable alerts for CPU, memory, disk, bandwidth, temperature, load average, and status.
  20→- **Multi-user**: Users manage their own systems. Admins can share systems across users.
  21→- **OAuth / OIDC**: Supports many OAuth2 providers. Password auth can be disabled.
  22→- **Automatic backups**: Save to and restore from disk or S3-compatible storage.
  23→<!-- - **REST API**: Use or update your data in your own scripts and applications. -->
  25→## Architecture
  26→
  27→Beszel consists of two main components: the **hub** and the **agent**.
  28→
  29→- **Hub**: A web application built on [PocketBase](https://pocketbase.io/) that provides a dashboard for viewing and managing connected systems.
  30→- **Agent**: Runs on each system you want to monitor and communicates system metrics to the hub.
  32→## Getting started
  33→
  34→The [quick start guide](https://beszel.dev/guide/getting-started) and other documentation is available on our website, [beszel.dev](https://beszel.dev). You'll be up and running in a few minutes.

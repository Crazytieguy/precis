  3→# Click
  4→
  5→Click is a Python package for creating beautiful command line interfaces
  6→in a composable way with as little code as necessary. It's the "Command
  7→Line Interface Creation Kit". It's highly configurable but comes with
  8→sensible defaults out of the box.
  10→It aims to make the process of writing command line tools quick and fun
  11→while also preventing any frustration caused by the inability to
  12→implement an intended CLI API.
  13→
  14→Click in three points:
  15→
  16→-   Arbitrary nesting of commands
  17→-   Automatic help page generation
  18→-   Supports lazy loading of subcommands at runtime

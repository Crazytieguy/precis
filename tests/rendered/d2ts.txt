  26→# D2TS - Differential Dataflow in TypeScript <!-- omit in toc -->
  27→
  28→D2TS is a TypeScript implementation of [differential dataflow](https://github.com/TimelyDataflow/differential-dataflow) - a powerful data-parallel programming framework that enables incremental computations over changing input data.
  30→You can use D2TS to build data pipelines that can be executed incrementally, meaning you can process data as it comes in, and only recompute the parts that have changed. This could be as simple as remapping data, or as complex as performing a full join combining two datasources where one is a computed aggregate.
  31→
  32→D2TS can be used in conjunction with [ElectricSQL](https://electric-sql.com) to build data pipelines on top of [ShapeStreams](https://electric-sql.com/docs/api/clients/typescript#shapestream) that can be executed incrementally.
  33→
  34→A D2TS pipeline is also fully type safe, inferring the types at each step of the pipeline, and supports auto-complete in your IDE.

  51→## Key Features
  52→
  53→- **Incremental Processing**: Efficiently process changes to input data without recomputing everything
  54→- **Rich Operators**: Supports common operations with a pipeline API:
  55→  - [`buffer`](#buffer): Buffer and emit versions when they are complete
  56→  - [`concat`](#concat): Concatenate two streams
  57→  - [`consolidate`](#consolidate): Consolidates the elements in the stream at each version
  58→  - [`count`](#count): Count elements by key
  59→  - [`distinct`](#distinct): Remove duplicates
  60→  - [`filter`](#filter): Filter elements based on predicates
  61→  - [`iterate`](#iterate): Perform iterative computations
  62→  - [`join`](#join): Join two streams
  63→  - [`keyBy`](#keyBy): Key a stream by a property
  64→  - [`map`](#map): Transform elements in a stream
  65→  - [`reduce`](#reduce): Aggregate values by key
  66→  - [`rekey`](#rekey): Change the key of a keyed stream
  67→  - [`unkey`](#unkey): Remove keys from a keyed stream
  68→  - [`output`](#output): Output the messages of the stream
  69→  - [`pipe`](#pipe): Build a pipeline of operators enabling reuse of combinations of operators
  70→- **SQLite Integration**: Optional SQLite backend for persisting operator state allowing for larger datasets and resumable pipelines
  71→- **Type Safety**: Full TypeScript type safety and inference through the pipeline API

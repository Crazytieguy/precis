  26→## Introduction
  27→
  28→**Enclosed** is a minimalistic web application designed for sending private and secure notes.
  30→All notes are end-to-end encrypted, ensuring that the server and storage have zero knowledge of the content. Users can set a password, define an expiration period (TTL), and choose to have the note self-destruct after being read.
  31→
  32→A live instance is available at [enclosed.cc](https://enclosed.cc).
  33→
  34→[![Enclosed](./.github/enclosed-mockup.png)](https://enclosed.cc)

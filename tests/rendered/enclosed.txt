  26→## Introduction
  27→
  28→**Enclosed** is a minimalistic web application designed for sending private and secure notes.
  30→All notes are end-to-end encrypted, ensuring that the server and storage have zero knowledge of the content. Users can set a password, define an expiration period (TTL), and choose to have the note self-destruct after being read.
  31→
  32→A live instance is available at [enclosed.cc](https://enclosed.cc).
  33→
  34→[![Enclosed](./.github/enclosed-mockup.png)](https://enclosed.cc)
  36→## Features
  37→
  38→- **End-to-End Encryption**: Your notes are encrypted on the client side, using AES-GCM with a 256-bit key derived using PBKDF2.
  39→- **File Attachments**: Share files securely with your notes.
  40→- **Zero Knowledge**: The server does not have access to the content of the notes or files.
  41→- **Configurable Security Options**: Set a password, expiration time, and choose self-destruction after the note is read.
  42→- **Minimalistic UI**: Simple and intuitive user interface for quick note sharing.
  43→- **i18n Support**: Available in multiple languages.
  44→- **Authentication**: Optional email/password authentication to create notes.
  45→- **Dark Mode**: A dark theme for late-night note sharing.
  46→- **Responsive Design**: Works on all devices, from desktops to mobile phones.
  47→- **Open Source**: The source code is available under the Apache 2.0 License.
  48→- **Self-Hostable**: Run your instance of Enclosed for private note sharing.
  49→- **CLI**: A command-line interface for creating notes from the terminal.
  50→- **Very low environmental impact**: the app and the docs is rated A+ on websitecarbon.com (see [here](https://www.websitecarbon.com/website/enclosed-cc/) and [here](https://www.websitecarbon.com/website/docs-enclosed-cc/)).

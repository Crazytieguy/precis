  10→# `htmy`
  11→
  12→**Async**, **pure-Python** server-side rendering engine.
  13→
  14→Unleash your creativity with the full power and Python, without the hassle of learning a new templating language or dealing with its limitations!
  16→## Key features
  17→
  18→- **Async**-first, to let you make the best use of modern async tools.
  19→- **Powerful**, React-like **context support**, so you can avoid prop-drilling.
  20→- Sync and async **function components** with **decorator syntax**.
  21→- All baseline **HTML** tags built-in.
  22→- **Async HTML streaming** support for optimal TTFB (time to first byte).
  23→- Support for **native HTML/XML** documents with dynamic formatting and **slot rendering**, **without custom syntax**.
  24→- **Markdown** support with tools for customization.
  25→- Async, JSON based **internationalization**.
  26→- Built-in, easy to use `ErrorBoundary` component for graceful error handling.
  27→- **Unopinionated**: use the backend, CSS, and JS frameworks of your choice, the way you want to use them.
  28→- Everything is **easily customizable**, from the rendering engine to components, formatting and context management.
  29→- Automatic and customizable **property-name conversion** from snake case to kebab case.
  30→- **Compatible** with any other templating library through wrappers.
  31→- **Fully-typed**.

  353→## Dependencies
  354→
  355→The library aims to minimze its dependencies. Currently the following dependencies are required:
  356→
  357→- `anyio`: for async file operations and networking.
  358→- `async-lru`: for async caching.
  359→- `markdown`: for markdown parsing.

  362→
  363→Use `ruff` for linting and formatting, `mypy` for static code analysis, and `pytest` for testing.

  365→The documentation is built with `zensical` and `mkdocstrings`.

  13→## Introduction
  14→
  15→`htop` is a cross-platform interactive process viewer.
  16→
  17→`htop` allows scrolling the list of processes vertically and horizontally to see their full command lines and related information like memory and CPU consumption.
  18→Also system wide information, like load average or swap usage, is shown.
  19→
  20→The information displayed is configurable through a graphical setup and can be sorted and filtered interactively.
  21→
  22→Tasks related to processes (e.g. killing and renicing) can be done without entering their PIDs.
  23→
  24→Running `htop` requires `ncurses` libraries, typically named libncurses(w).
  25→
  26→`htop` is written in C.
  27→
  28→For more information and details visit [htop.dev](https://htop.dev).
  30→## Usage
  31→See the manual page (`man htop`) or the help menu (`h` or `F1` inside `htop`) for a list of supported key commands.
  32→
  33→### Quick Start
  34→
  35→Some common actions to get you started with `htop`
  36→
  37→- Search processes: press `/`
  38→- Filter processes: press `\`
  39→- Toggle tree view: press `t`
  40→- Change process sort column: press `.`
  41→- Kill a process: select the process and press `k`
  43→## Build instructions
  44→
  45→### Prerequisite
  46→List of build-time dependencies:
  47→  * standard GNU autotools-based C toolchain
  48→    - C99 compliant compiler
  49→    - `autoconf`
  50→    - `automake`
  51→    - `autotools`
  52→  * `ncurses`
  53→
  54→**Note about `ncurses`:**
  55→> `htop` requires `ncurses` 6.0. Be aware the appropriate package is sometimes still called libncurses5 (on Debian/Ubuntu). Also `ncurses` usually comes in two flavours:
  56→>* With Unicode support.
  57→>* Without Unicode support.
  58→>
  59→> This is also something that is reflected in the package name on Debian/Ubuntu (via the additional 'w' - 'w'ide character support).
  61→List of additional build-time dependencies (based on feature flags):
  62→*  `pkg-config`
  63→*  `sensors`
  64→*  `hwloc`
  65→*  `libcap` (v2.21 or later)
  66→*  `libnl-3` and `libnl-genl-3`
  67→

  74→sudo apt install libncursesw5-dev autotools-dev autoconf automake build-essential

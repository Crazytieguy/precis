  17→## Usage
  18→
  19→Create a `db.json` or `db.json5` file
  20→
  21→```json
  22→{
  23→  "$schema": "./node_modules/json-server/schema.json",
  24→  "posts": [
  25→    { "id": "1", "title": "a title", "views": 100 },
  26→    { "id": "2", "title": "another title", "views": 200 }
  27→  ],
  28→  "comments": [
  29→    { "id": "1", "text": "a comment about post 1", "postId": "1" },
  30→    { "id": "2", "text": "another comment about post 1", "postId": "1" }
  31→  ],
  32→  "profile": {
  33→    "name": "typicode"
  34→  }
  35→}
  36→```
  38→<details>
  39→
  40→<summary>View db.json5 example</summary>
  41→
  42→```json5
  43→{
  44→  posts: [
  45→    { id: "1", title: "a title", views: 100 },
  46→    { id: "2", title: "another title", views: 200 },
  47→  ],
  48→  comments: [
  49→    { id: "1", text: "a comment about post 1", postId: "1" },
  50→    { id: "2", text: "another comment about post 1", postId: "1" },
  51→  ],
  52→  profile: {
  53→    name: "typicode",
  54→  },
  55→}
  56→```
  57→
  58→You can read more about JSON5 format [here](https://github.com/json5/json5).
  60→</details>
  61→
  62→Start JSON Server
  63→
  64→```bash
  65→npx json-server db.json
  66→```
  67→
  68→This starts the server at `http://localhost:3000`. You should see:
  69→```
  70→JSON Server started on PORT :3000
  71→http://localhost:3000
  72→```
  73→
  74→Access your REST API:
  75→
  76→```bash
  77→curl http://localhost:3000/posts/1
  78→```
  79→
  80→**Response:**
  81→```json
  82→{
  83→  "id": "1",
  84→  "title": "a title",
  85→  "views": 100
  86→}
  87→```
  88→
  89→Run `json-server --help` for a list of options

  118→## Query Capabilities
  119→
  120→JSON Server supports advanced querying out of the box:
  121→
  122→```http
  123→GET /posts?views:gt=100                  # Filter by condition
  124→GET /posts?_sort=-views                  # Sort by field (descending)
  125→GET /posts?_page=1&_per_page=10          # Pagination
  126→GET /posts?_embed=comments               # Include relations
  127→GET /posts?_where={"or":[...]}           # Complex queries
  128→```
  129→
  130→See detailed documentation below for each feature.
  132→## Routes
  133→
  134→### Array Resources
  135→
  136→For array resources like `posts` and `comments`:
  137→
  138→```http
  139→GET    /posts
  140→GET    /posts/:id
  141→POST   /posts
  142→PUT    /posts/:id
  143→PATCH  /posts/:id
  144→DELETE /posts/:id
  145→```
  146→
  147→### Object Resources
  148→
  149→For singular object resources like `profile`:
  150→
  151→```http
  152→GET   /profile
  153→PUT   /profile
  154→PATCH /profile
  155→```

  241→## Static Files
  242→
  243→JSON Server automatically serves files from the `./public` directory.
  244→
  245→To serve additional static directories:
  246→
  247→```bash
  248→json-server db.json -s ./static
  249→json-server db.json -s ./static -s ./node_modules
  250→```
  251→
  252→Static files are served with standard MIME types and can include HTML, CSS, JavaScript, images, and other assets.

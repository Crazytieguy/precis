  1→# k(r)ep - A high-performance string search utility

  6→`krep` is an optimized string search utility designed for maximum throughput and efficiency when processing large files and directories. It is built with performance in mind, offering multiple search algorithms and SIMD acceleration when available.
  8→> **Note:**  
  9→> Krep is not intended to be a full replacement or direct competitor to feature-rich tools like `grep` or `ripgrep`. Instead, it aims to be a minimal, efficient, and pragmatic tool focused on speed and simplicity.
  10→>
  11→> Krep provides the essential features needed for fast searching, without the extensive options and complexity of more comprehensive search utilities. Its design philosophy is to deliver the fastest possible search for the most common use cases, with a clean and minimal interface.

  19→## Key Features
  …
  22→- **Algorithm selection**: Automatic smart selection with optional `--algo` override for fine-tuning
  …
  24→- **Memory-mapped I/O**: Maximizes throughput when processing large files
  25→- **Multi-threaded search**: Automatically parallelizes searches across available CPU cores
  26→- **Regex support**: POSIX Extended Regular Expression searching
  27→- **Multiple pattern search**: Efficiently search for multiple patterns simultaneously using Aho-Corasick
  28→- **Recursive directory search**: Skip binary files and common non-code directories
  29→- **Gitignore support**: Respect `.gitignore` files during recursive search with `--gitignore`
  30→- **Stdin pattern input**: Read patterns from stdin with `-f -` for seamless pipeline integration
  31→- **Colored output**: Highlights matches for better readability
  …
  33→- **Specialized algorithms**: Optimized handling for single-character and short patterns
  34→- **Match Limiting**: Stop searching a file after a specific number of matching lines are found.

  134→## Command Line Options
  136→- `-i, --ignore-case` Case-insensitive search
  137→- `-c, --count` Count matching lines only
  138→- `-o, --only-matching` Print only the matched parts of lines
  139→- `-e PATTERN, --pattern=PATTERN` Specify pattern(s). Can be used multiple times.
  140→- `-f FILE, --file=FILE` Read patterns from FILE, one per line. Use `-` for stdin.
  141→- `-m NUM, --max-count=NUM` Stop searching each file after finding NUM matching lines.
  142→- `-E, --extended-regexp` Use POSIX Extended Regular Expressions
  143→- `-F, --fixed-strings` Interpret pattern as fixed string(s) (default unless -E is used)
  144→- `-r, --recursive` Recursively search directories
  145→- `--gitignore` Respect `.gitignore` files during recursive search
  146→- `--algo=ALGO` Force search algorithm: `auto` (default), `bm` (Boyer-Moore), `kmp` (KMP)
  147→- `-t NUM, --threads=NUM` Use NUM threads for file search (default: auto)
  148→- `-s STRING, --string=STRING` Search in the provided STRING instead of file(s)
  149→- `-w, --word-regexp` Match only whole words
  150→- `--color[=WHEN]` Control color output ('always', 'never', 'auto')
  151→- `--no-simd` Explicitly disable SIMD acceleration
  152→- `-v, --version` Show version information
  153→- `-h, --help` Show help message

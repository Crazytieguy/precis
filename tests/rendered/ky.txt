  11→> Ky is a tiny and elegant HTTP client based on the [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/WindowOrWorkerGlobalScope/fetch)
  …
  16→Ky targets [modern browsers](#browser-support), Node.js, Bun, and Deno.
  17→
  18→It's just a tiny package with no dependencies.
  19→
  20→## Benefits over plain `fetch`
  21→
  22→- Simpler API
  23→- Method shortcuts (`ky.post()`)
  24→- Treats non-2xx status codes as errors (after redirects)
  25→- Retries failed requests
  26→- JSON option
  27→- Timeout support
  28→- URL prefix option
  29→- Instances with custom defaults
  30→- Hooks
  31→- TypeScript niceties (e.g. `.json()` supports generics and defaults to `unknown`, not `any`)

  86→
  87→### ky(input, options?)
  88→
  89→The `input` and `options` are the same as [`fetch`](https://developer.mozilla.org/en-US/docs/Web/API/WindowOrWorkerGlobalScope/fetch), with additional `options` available (see below).
  90→
  91→Returns a [`Response` object](https://developer.mozilla.org/en-US/docs/Web/API/Response) with [`Body` methods](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch#body) added for convenience. So you can, for example, call `ky.get(input).json()` directly without having to await the `Response` first.

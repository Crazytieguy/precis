  9→##  Introduction
  10→
  11→linkding is a bookmark manager that you can host yourself.
  12→It's designed be to be minimal, fast, and easy to set up using Docker.
  14→The name comes from:
  15→- *link* which is often used as a synonym for URLs and bookmarks in common language
  16→- *Ding* which is German for thing
  17→- ...so basically something for managing your links
  18→
  19→**Feature Overview:**
  20→- Clean UI optimized for readability
  21→- Organize bookmarks with tags
  22→- Bulk editing, Markdown notes, read it later functionality
  23→- Share bookmarks with other users or guests
  24→- Automatically provides titles, descriptions and icons of bookmarked websites
  25→- Automatically archive websites, either as local HTML file or on Internet Archive
  26→- Import and export bookmarks in Netscape HTML format
  27→- Installable as a Progressive Web App (PWA)
  28→- Extensions for [Firefox](https://addons.mozilla.org/firefox/addon/linkding-extension/) and [Chrome](https://chrome.google.com/webstore/detail/linkding-extension/beakmhbijpdhipnjhnclmhgjlddhidpe), as well as a bookmarklet
  29→- SSO support via OIDC or authentication proxies
  30→- REST API for developing 3rd party apps
  31→- Admin panel for user self-service and raw data access
  32→
  33→
  34→**Demo:** https://demo.linkding.link/
  35→

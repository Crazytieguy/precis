  1→# MCPHost 🤖
  2→
  3→A CLI host application that enables Large Language Models (LLMs) to interact with external tools through the Model Context Protocol (MCP). Currently supports Claude, OpenAI, Google Gemini, and Ollama models.
  5→Discuss the Project on [Discord](https://discord.gg/RqSS2NQVsY)
  …
  60→## Features ✨
  61→
  62→- Interactive conversations with multiple AI models
  63→- **Non-interactive mode** for scripting and automation
  64→- **Script mode** for executable YAML-based automation scripts
  65→- Support for multiple concurrent MCP servers
  66→- **Tool filtering** with `allowedTools` and `excludedTools` per server
  67→- Dynamic tool discovery and integration
  68→- Tool calling capabilities across all supported models
  69→- Configurable MCP server locations and arguments
  70→- Consistent command interface across model types
  71→- Configurable message history window for context management
  72→- **OAuth authentication** support for Anthropic (alternative to API keys)
  73→- **Hooks system** for custom integrations and security policies
  74→- **Environment variable substitution** in configs and scripts
  75→- **Builtin servers** for common functionality (filesystem, bash, todo, http)

    27→	Short: "List all configured hooks",

    29→		config, err := hooks.LoadHooksConfig()

    31→			return fmt.Errorf("loading hooks config: %w", err)

    33→
    34→		w := tabwriter.NewWriter(os.Stdout, 0, 0, 2, ' ', 0)
    35→		fmt.Fprintln(w, "EVENT\tMATCHER\tCOMMAND\tTIMEOUT")
    36→
    37→		for event, matchers := range config.Hooks {
    38→			for _, matcher := range matchers {
    39→				for _, hook := range matcher.Hooks {
    40→					timeout := "60s"
    41→					if hook.Timeout > 0 {
    42→						timeout = fmt.Sprintf("%ds", hook.Timeout)

    47→			}
    48→		}

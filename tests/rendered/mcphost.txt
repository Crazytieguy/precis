  1→# MCPHost 🤖
  2→
  3→A CLI host application that enables Large Language Models (LLMs) to interact with external tools through the Model Context Protocol (MCP). Currently supports Claude, OpenAI, Google Gemini, and Ollama models.
  5→Discuss the Project on [Discord](https://discord.gg/RqSS2NQVsY)
  …
  60→## Features ✨
  61→
  62→- Interactive conversations with multiple AI models
  63→- **Non-interactive mode** for scripting and automation
  64→- **Script mode** for executable YAML-based automation scripts
  65→- Support for multiple concurrent MCP servers
  66→- **Tool filtering** with `allowedTools` and `excludedTools` per server
  67→- Dynamic tool discovery and integration
  68→- Tool calling capabilities across all supported models
  69→- Configurable MCP server locations and arguments
  70→- Consistent command interface across model types
  71→- Configurable message history window for context management
  72→- **OAuth authentication** support for Anthropic (alternative to API keys)
  73→- **Hooks system** for custom integrations and security policies
  74→- **Environment variable substitution** in configs and scripts
  75→- **Builtin servers** for common functionality (filesystem, bash, todo, http)

    1→# MCPHost SDK
    2→
    3→The MCPHost SDK allows you to use MCPHost programmatically from Go applications without spawning OS processes.
    5→## Installation
    6→
    7→```bash
    8→go get github.com/mark3labs/mcphost
    9→```
    11→## Basic Usage
    12→
    13→```go
    14→package main
    15→
    16→import (
    17→    "context"
    18→    "fmt"
    19→    "log"
    20→    
    21→    "github.com/mark3labs/mcphost/sdk"
    22→)
    23→
    24→func main() {
    25→    ctx := context.Background()
    26→    
    27→    // Create MCPHost instance with default configuration
    28→    host, err := sdk.New(ctx, nil)
    29→    if err != nil {
    30→        log.Fatal(err)
    31→    }
    32→    defer host.Close()
    33→    
    34→    // Send a prompt
    35→    response, err := host.Prompt(ctx, "What is 2+2?")
    36→    if err != nil {
    37→        log.Fatal(err)
    38→    }
    39→    
    40→    fmt.Println(response)
    41→}
    42→```
    44→## Configuration
    45→
    46→The SDK behaves identically to the CLI:
    47→- Loads configuration from `~/.mcphost.yml` by default
    48→- Creates default configuration if none exists
    49→- Respects all environment variables (`MCPHOST_*`)
    50→- Uses the same defaults as the CLI
    51→
    52→### Options
    53→
    54→You can override specific settings:
    55→
    56→```go
    57→host, err := sdk.New(ctx, &sdk.Options{
    58→    Model:        "ollama:llama3",           // Override model
    59→    SystemPrompt: "You are a helpful bot",   // Override system prompt
    60→    ConfigFile:   "/path/to/config.yml",     // Use specific config file
    61→    MaxSteps:     10,                        // Override max steps
    62→    Streaming:    true,                      // Enable streaming
    63→    Quiet:        true,                      // Suppress debug output
    64→})
    65→```

  1→# MCPHost 🤖
  2→
  3→A CLI host application that enables Large Language Models (LLMs) to interact with external tools through the Model Context Protocol (MCP). Currently supports Claude, OpenAI, Google Gemini, and Ollama models.
  5→Discuss the Project on [Discord](https://discord.gg/RqSS2NQVsY)

  41→## Overview 🌟
  42→
  43→MCPHost acts as a host in the MCP client-server architecture, where:
  44→- **Hosts** (like MCPHost) are LLM applications that manage connections and interactions
  45→- **Clients** maintain 1:1 connections with MCP servers
  46→- **Servers** provide context, tools, and capabilities to the LLMs
  47→
  48→This architecture allows language models to:
  49→- Access external tools and data sources 🛠️
  50→- Maintain consistent context across interactions 🔄
  51→- Execute commands and retrieve information safely 🔒
  52→
  53→Currently supports:
  54→- Anthropic Claude models (Claude 3.5 Sonnet, Claude 3.5 Haiku, etc.)
  55→- OpenAI models (GPT-4, GPT-4 Turbo, GPT-3.5, etc.)
  56→- Google Gemini models (Gemini 2.0 Flash, Gemini 1.5 Pro, etc.)
  57→- Any Ollama-compatible model with function calling support
  58→- Any OpenAI-compatible API endpoint
  60→## Features ✨
  61→
  62→- Interactive conversations with multiple AI models
  63→- **Non-interactive mode** for scripting and automation
  64→- **Script mode** for executable YAML-based automation scripts
  65→- Support for multiple concurrent MCP servers
  66→- **Tool filtering** with `allowedTools` and `excludedTools` per server
  67→- Dynamic tool discovery and integration
  68→- Tool calling capabilities across all supported models
  69→- Configurable MCP server locations and arguments
  70→- Consistent command interface across model types
  71→- Configurable message history window for context management
  72→- **OAuth authentication** support for Anthropic (alternative to API keys)
  73→- **Hooks system** for custom integrations and security policies
  74→- **Environment variable substitution** in configs and scripts
  75→- **Builtin servers** for common functionality (filesystem, bash, todo, http)
  77→## Requirements 📋
  78→
  79→- Go 1.23 or later
  80→- For OpenAI/Anthropic: API key for the respective provider
  81→- For Ollama: Local Ollama installation with desired models
  82→- For Google/Gemini: Google API key (see https://aistudio.google.com/app/apikey)
  83→- One or more MCP-compatible tool servers

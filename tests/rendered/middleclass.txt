README.md
  1→middleclass
  2→===========
  …
  7→A simple OOP library for Lua. It has inheritance, metamethods (operators), class variables and weak mixin support.
  9→Quick Look
  10→==========
  11→
  12→```lua
  13→local class = require 'middleclass'
  14→
  15→local Fruit = class('Fruit') -- 'Fruit' is the class' name
  16→
  17→function Fruit:initialize(sweetness)
  18→  self.sweetness = sweetness
  19→end
  20→
  21→Fruit.static.sweetness_threshold = 5 -- class variable (also admits methods)
  22→
  23→function Fruit:isSweet()
  24→  return self.sweetness > Fruit.sweetness_threshold
  25→end
  26→
  27→local Lemon = class('Lemon', Fruit) -- subclassing
  28→
  29→function Lemon:initialize()
  30→  Fruit.initialize(self, 1) -- invoking the superclass' initializer
  31→end
  32→
  33→local lemon = Lemon:new()
  34→
  35→print(lemon:isSweet()) -- false
  36→```

  47→Installation
  48→============
  49→
  50→Just copy the middleclass.lua file wherever you want it (for example on a lib/ folder). Then write this in any Lua file where you want to use it:
  51→
  52→```lua
  53→local class = require 'middleclass'
  54→```

UPDATING.md
  1→Updating from 3.x to 4.x
  2→========================
  3→
  4→In middleclass 4.0 there is no global `Object` class any more. Classes created with `class(<name>)` don't have a superclass any more.
  5→If you need a global `Object` class, you must create it explicitly and then use it when creating new classes:
  6→
  7→```lua
  8→local Object = class('Object')
  9→
  10→...
  11→
  12→local MyClass = class('MyClass', Object)
  13→```
  14→
  15→If you are using a library which depends on the internal implementation of middleclass they might not work with middleclass 4.0. You might need to update those other libraries.
  16→
  17→Middleclass 4.0 comes with support for `__index` metamethod support. If your library manipulated the classes' `__instanceDict` internal attribute, you might do the same thing now using `__index` instead.
  19→Also note that the class method `:implements` has been removed.
  20→
  21→Updating from 2.x to 3.x
  22→========================
  23→
  24→Middleclass used to expose several global variables on the main scope. It does not do that anymore.
  25→
  26→`class` is now returned by `require 'middleclass'`, and it is not set globally. So you can do this:
  27→
  28→```lua
  29→local class = require 'middleclass'
  30→local MyClass = class('MyClass') -- works as before
  31→```
  32→
  33→`Object` is not a global variable any more. But you can get it from `class.Object`
  34→
  35→```lua
  36→local class = require 'middleclass'
  37→local Object = class.Object
  38→
  39→print(Object) -- prints 'class Object'
  40→```

  14→Neco is a C library that provides concurrency using coroutines.
  15→It's small & fast, and intended to make concurrent I/O & network programming 
  16→easy.
  17→
  18→## Features
  19→
  20→- [Coroutines](docs/API.md#basic-operations): starting, sleeping, suspending, resuming, yielding, and joining.
  21→- [Synchronization](docs/API.md#channels): channels, generators, mutexes, condition variables, and waitgroups.
  22→- Support for [deadlines and cancelation](docs/API.md#deadlines-and-cancelation).
  23→- [Posix friendly](docs/API.md#posix-wrappers) interface using file descriptors.
  24→- Additional APIs for [networking](docs/API.md#networking-utilities),
  25→[signals](docs/API.md#signals), [random data](docs/API.md#random-number-generator), [streams](docs/API.md#streams-and-buffered-io), and [buffered I/O](docs/API.md#streams-and-buffered-io).
  26→- Lightweight runtime with a fair and deterministic [scheduler](#the-scheduler).
  27→- [Fast](#fast-context-switching) user-space context switching. Uses assembly in most cases.
  28→- Stackful coroutines that are nestable, with their life times fully managed by the scheduler.
  29→- Cross-platform. Linux, Mac, FreeBSD. _(Also WebAssembly and Windows with [some limitations](#platform-notes))_.
  30→- Single file amalgamation. No dependencies.
  31→- [Test suite](tests/README.md) with 100% coverage using sanitizers and [Valgrind](https://valgrind.org).
  32→
  33→For a deeper dive, check out the [API reference](docs/API.md).
  35→It may also be worthwhile to see the [Bluebox](https://github.com/tidwall/bluebox) project for a
  36→more complete example of using Neco, including benchmarks.
  38→## Goals
  39→
  40→- Give C programs fast single-threaded concurrency.
  41→- To use a concurrency model that resembles the simplicity of pthreads or Go.
  42→- Provide an API for concurrent networking and I/O.
  43→- Make it easy to interop with existing Posix functions.
  44→
  45→It's a non-goal for Neco to provide a scalable multithreaded runtime, where the
  46→coroutine scheduler is shared among multiple cpu cores. Or to use other

  49→## Using
  50→
  51→Just drop the "neco.c" and "neco.h" files into your project. Most modern C compilers should work.
  52→
  53→```sh
  54→cc -c neco.c
  55→```

  30→Rich is a Python library for _rich_ text and beautiful formatting in the terminal.
  31→
  32→The [Rich API](https://rich.readthedocs.io/en/latest/) makes it easy to add color and style to terminal output. Rich can also render pretty tables, progress bars, markdown, syntax highlighted source code, tracebacks, and more — out of the box.
  …
  36→For a video introduction to Rich see [calmcode.io](https://calmcode.io/rich/introduction.html) by [@fishnets88](https://twitter.com/fishnets88).
  37→
  38→See what [people are saying about Rich](https://www.willmcgugan.com/blog/pages/post/rich-tweets/).
  40→## Compatibility
  41→
  42→Rich works with Linux, macOS and Windows. True color / emoji works with new Windows Terminal, classic terminal is limited to 16 colors. Rich requires Python 3.8 or later.
  44→Rich works with [Jupyter notebooks](https://jupyter.org/) with no additional configuration required.
  46→## Installing
  47→
  48→Install with `pip` or your favorite PyPI package manager.
  49→
  50→```sh
  51→python -m pip install rich
  52→```
  53→
  54→Run the following to test Rich output on your terminal:
  55→
  56→```sh
  57→python -m rich
  58→```

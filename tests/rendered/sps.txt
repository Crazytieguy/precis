  25→sps is a next‑generation, Rust‑powered package manager inspired by Homebrew. It installs and manages:
  27→- **Formulae:** command‑line tools, libraries, and languages
  28→- **Casks:** desktop applications and related artifacts on macOS
  29→
  30→> _ARM only for now, might add x86 support eventually_

  34→## ⚙️ Project Structure
  35→
  36→- **sps‑core** Core library: fetching, dependency resolution, archive extraction, artifact handling (apps, binaries, pkg installers, fonts, plugins, zap/preflight/uninstall stanzas, etc.)
  37→
  38→- **sps‑cli** Command‑line interface: `sps` executable wrapping the core library.

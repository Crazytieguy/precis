  5→An extremely small, "fast enough" vector search SQLite extension that runs
  6→anywhere! A successor to [`sqlite-vss`](https://github.com/asg017/sqlite-vss)
  8→<!-- deno-fmt-ignore-start -->
  9→
  10→> [!IMPORTANT]
  11→> _`sqlite-vec` is a pre-v1, so expect breaking changes!_
  12→
  13→<!-- deno-fmt-ignore-end -->
  14→
  15→- Store and query float, int8, and binary vectors in `vec0` virtual tables
  16→- Written in pure C, no dependencies, runs anywhere SQLite runs
  17→  (Linux/MacOS/Windows, in the browser with WASM, Raspberry Pis, etc.)
  18→- Store non-vector data in metadata, auxiliary, or partition key columns

  61→## Sample usage
  62→
  63→```sql
  64→.load ./vec0
  65→
  66→create virtual table vec_examples using vec0(
  67→  sample_embedding float[8]
  68→);
  69→
  70→-- vectors can be provided as JSON or in a compact binary format
  71→insert into vec_examples(rowid, sample_embedding)
  72→  values
  73→    (1, '[-0.200, 0.250, 0.341, -0.211, 0.645, 0.935, -0.316, -0.924]'),
  74→    (2, '[0.443, -0.501, 0.355, -0.771, 0.707, -0.708, -0.185, 0.362]'),
  75→    (3, '[0.716, -0.927, 0.134, 0.052, -0.669, 0.793, -0.634, -0.162]'),
  76→    (4, '[-0.710, 0.330, 0.656, 0.041, -0.990, 0.726, 0.385, -0.958]');
  77→
  78→
  79→-- KNN style query
  80→select
  81→  rowid,
  82→  distance
  83→from vec_examples
  84→where sample_embedding match '[0.890, 0.544, 0.825, 0.961, 0.358, 0.0196, 0.521, 0.175]'
  85→order by distance
  86→limit 2;
  87→/*
  88→┌───────┬──────────────────┐
  89→│ rowid │     distance     │
  90→├───────┼──────────────────┤
  91→│ 2     │ 2.38687372207642 │
  92→│ 1     │ 2.38978505134583 │
  93→└───────┴──────────────────┘
  94→*/
  95→```

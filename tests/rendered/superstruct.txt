  36→Superstruct makes it easy to define interfaces and then validate JavaScript data against them. Its type annotation API was inspired by [Typescript](https://www.typescriptlang.org/docs/handbook/basic-types.html), [Flow](https://flow.org/en/docs/types/), [Go](https://gobyexample.com/structs), and [GraphQL](http://graphql.org/learn/schema/), giving it a familiar and easy to understand API.
  38→But Superstruct is designed for validating data at runtime, so it throws (or returns) detailed runtime errors for you or your end users. This is especially useful in situations like accepting arbitrary input in a REST or GraphQL API. But it can even be used to validate internal data structures at runtime when needed.

  42→### Usage
  43→
  44→Superstruct allows you to define the shape of data you want to validate:
  46→```js
  47→import { assert, object, number, string, array } from 'superstruct'
  48→
  49→const Article = object({
  50→  id: number(),
  51→  title: string(),
  52→  tags: array(string()),
  53→  author: object({
  54→    id: number(),
  55→  }),
  56→})
  57→
  58→const data = {
  59→  id: 34,
  60→  title: 'Hello World',
  61→  tags: ['news', 'features'],
  62→  author: {
  63→    id: 1,
  64→  },
  65→}
  66→
  67→assert(data, Article)
  68→// This will throw an error when the data is invalid.
  69→// If you'd rather not throw, you can use `is()` or `validate()`.
  70→```

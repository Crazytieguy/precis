  8→## Features
  9→
  10→<img src="assets/demo.png" width="820px" />
  11→
  12→**Tock** is a powerful time tracking tool for the command line. It saves activity logs as plaintext files and provides an interactive terminal UI for viewing your time.
  13→
  14→Features include:
  15→
  16→- 📝 **Simple plaintext format** - Activities stored in human-readable files
  17→- 📅 **Notes & Tags** - Attach detailed notes and tags to activities
  18→- 🎨 **Interactive TUI** - Beautiful terminal calendar view using Bubble Tea
  19→- ⚡ **Fast & Lightweight** - Single binary, no dependencies
  20→- 🔄 **Compatible** - Reads/writes Bartib file format and TimeWarrior data files
  21→- 🎨 **Customizable Themes** - Multiple color themes and custom color support
  22→- 📅 **iCal Export** - Generate .ics files for calendar integration, or sync with system calendars (macOS only)

  602→## Update Check
  603→
  604→Tock automatically checks for updates once a week. When a new version is available, you will see a notification after running commands like `start` or `stop`.
  605→
  606→You can disable this check by setting `check_updates: false` in your configuration file or using the environment variable `TOCK_CHECK_UPDATES=false`.
  608→## File Format
  609→
  610→Activities are stored in plaintext format (compatible with Bartib):
  611→
  612→```
  613→  2025-12-10 09:00 - 2025-12-10 11:30 | Project Name | Task description
  614→  2025-12-10 13:00 | Another Project | Ongoing task
  615→```
  616→
  617→You can edit this file manually with any text editor.

  709→## Inspiration
  710→
  711→Tock is inspired by and compatible with [Bartib](https://github.com/nikolassv/bartib) - an excellent time tracking tool written in Rust by Nikolas Schmidt-Voigt. It's saved me countless hours and helped me stay organized, so I wanted to create a similar tool in Go with a clean architecture approach and an interactive terminal UI.

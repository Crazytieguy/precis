  142→## How to use the xLSTM architecture from our NeurIPS paper
  143→
  144→For non language applications or for integrating in other architectures you can use the `xLSTMBlockStack` and for language modeling or other token-based applications you can use the `xLSTMLMModel`.
  145→
  146→### Using the sLSTM CUDA kernels
  147→
  148→For the CUDA version of sLSTM, you need Compute Capability >= 8.0, see [https://developer.nvidia.com/cuda-gpus](https://developer.nvidia.com/cuda-gpus). If you have problems with the compilation, please try (thanks to [@zia1138](https://github.com/zia1138) for pointing out):
  149→```bash
  150→export TORCH_CUDA_ARCH_LIST="8.0;8.6;9.0"
  151→```
  153→For all kinds of custom setups with torch and CUDA, keep in mind that versions have to match. Also, to make sure the correct CUDA libraries are included you can use the "XLSTM_EXTRA_INCLUDE_PATHS" environment variable now to inject different include paths, e.g.:
  154→
  155→```bash
  156→export XLSTM_EXTRA_INCLUDE_PATHS='/usr/local/include/cuda/:/usr/include/cuda/'
  157→```
  158→
  159→or within python:
  160→
  161→```python
  162→import os
  163→os.environ['XLSTM_EXTRA_INCLUDE_PATHS']='/usr/local/include/cuda/:/usr/include/cuda/'
  164→```
